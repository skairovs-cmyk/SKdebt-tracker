# 💸 DebtFlow — Учет обязательств и долгов

Веб-приложение для ведения учета задолженностей и финансовых обязательств в реальном времени.

## Особенности
- **Современный темный интерфейс (Dark Slate)**: адаптивный, красивый дизайн с микро-анимациями.
- **Интеграция с Firebase**: аутентификация пользователей и синхронизация базы данных в реальном времени.
- **Динамический реестр**: возможность добавления пользовательских столбцов («на лету») через настройки Firestore.
- **Статистика в реальном времени**: расчет чистого остатка долгов, суммы списаний за текущий календарный месяц и количества активных записей.
- **Безопасность**: изоляция данных между пользователями на уровне правил Cloud Firestore.

## Пошаговая инструкция по настройке и запуску

### Шаг 1. Настройка Firebase проекта

1. Перейдите в консоль Firebase: [https://console.firebase.google.com/](https://console.firebase.google.com/).
2. Нажмите **Add project** (Добавить проект), укажите любое имя (например, `DebtFlow`) и завершите создание.
3. В меню слева перейдите в **Build** -> **Authentication**:
   - Нажмите **Get Started** (Начать).
   - Выберите вкладку **Sign-in method** (Метод входа).
   - Выберите **Email/Password** (Электронная почта/Пароль), включите первую галочку (Enable) и нажмите **Save**.
4. В меню слева перейдите в **Build** -> **Firestore Database**:
   - Нажмите **Create database** (Создать базу данных).
   - Выберите любое удобное расположение сервера и нажмите **Next**.
   - Начните в режиме тестирования (**Start in test mode**) или сразу в режиме производства, после чего перейдите во вкладку **Rules** (Правила) сверху и вставьте правила из файла `firestore.rules`. Нажмите кнопку **Publish** (Опубликовать).

### Шаг 2. Получение конфигурации SDK

1. Перейдите на главную страницу настроек вашего проекта (иконка шестеренки в верхнем левом углу -> **Project settings**).
2. На вкладке **General** прокрутите вниз до раздела **Your apps** и добавьте новое веб-приложение (иконка `</>`).
3. Зарегистрируйте приложение под любым именем.
4. Вы увидите код инициализации, в котором будет объект `firebaseConfig` вида:
   ```javascript
   const firebaseConfig = {
     apiKey: "AIzaSy...",
     authDomain: "...",
     projectId: "...",
     storageBucket: "...",
     messagingSenderId: "...",
     appId: "..."
   };
   ```
5. Скопируйте этот JSON-объект (все, что внутри фигурных скобок `{ ... }` включительно).

---

### Шаг 3. Локальный запуск приложения

Для запуска приложения без необходимости устанавливать Node.js или Python, в папку проекта вложен PowerShell-скрипт `server.ps1`, который поднимает локальный HTTP-сервер на вашем ПК:

1. Откройте терминал PowerShell.
2. Перейдите в директорию проекта:
   ```powershell
   cd "C:\Users\101\Desktop\debt-tracker"
   ```
3. Запустите веб-сервер командой:
   ```powershell
   powershell -ExecutionPolicy Bypass -File server.ps1
   ```
4. Скрипт запустит HTTP-сервер на порту `8080` и автоматически откроет приложение в вашем браузере по адресу: [http://localhost:8080/](http://localhost:8080/).
5. Для остановки сервера нажмите **Ctrl+C** в окне PowerShell.

---

### Шаг 4. Настройка при первом запуске

1. При первом открытии [http://localhost:8080/](http://localhost:8080/) в браузере вы увидите экран **Настройка Firebase**.
2. Вставьте скопированный на Шаге 2 JSON-объект `firebaseConfig` в текстовое поле и нажмите **Сохранить настройки**.
3. Приложение перезагрузится, и вы увидите экран авторизации.
4. Вы можете зарегистрировать двух разных пользователей (например, `test1@domain.com` и `test2@domain.com`) с любыми паролями (не менее 6 символов).
5. После входа вы попадете в панель управления, где все изменения будут сохраняться в вашей БД Firebase в реальном времени!

## Публикация на GitHub Pages

Этот проект уже подготовлен для GitHub Pages:

- в корне есть [`index.html`](/C:/Users/101/Desktop/debt-tracker/index.html)
- добавлен файл [`.nojekyll`](/C:/Users/101/Desktop/debt-tracker/.nojekyll)
- добавлен workflow [`.github/workflows/pages.yml`](/C:/Users/101/Desktop/debt-tracker/.github/workflows/pages.yml)

### Что нужно сделать в GitHub

1. Создать репозиторий и загрузить в него файлы проекта.
2. В репозитории открыть `Settings` -> `Pages`.
3. В `Build and deployment` выбрать `GitHub Actions`.
4. Сделать `push` в ветку `main`.

### Чтобы Firebase работал на GitHub Pages

После публикации нужно добавить домен GitHub Pages в Firebase Console:

1. Открой `Firebase Console` -> `Authentication` -> `Settings`.
2. В `Authorized domains` добавь домен твоего сайта на GitHub Pages.
3. Проверь, что `Firestore`, `Authentication` и при необходимости `Storage` включены.

По официальной документации GitHub Pages публикует статические HTML/CSS/JS-файлы из репозитория, а для статического сайта рекомендуется использовать GitHub Actions или branch publishing source. GitHub Pages также поддерживает HTTPS автоматически. Firebase для веб-приложения подключается через объект `firebaseConfig`.
